# Analiza-wystąpień-w-Eurowizji
Analiza wystąpień w Eurowizji pisana w Pythonie.
W pliku Eurowizja.ipyng jest zawarta analiza wyników konkursu Eurowizji pisana w Pythonie w Visual Studio Code.
Dane contest_data.csv oraz song_data.csv zostały ściągnięte z www.kaggle.com i przeanalizowane korzystając z rozszerzeń numpy, pandas, matplotlib, math oraz seaborn.
Pliki png (najlepsze i najgorsze wystąpienia.png, punkty a gatunek muzyki tabela.png, punkty a gatunek muzyki.png, różnice między regionami.png, średnia liczba punktów.png, punkty finałowe a język.pmg, roznice jury a telewidzowie.png, tabela język.png) ilustrują wykonane tabelki oraz wykresy
